# Lightweight Web-based Postman Alternative

A simple, handy web-based tool for sending API requests. This project was developed during internet outages when the main Postman application was inaccessible and its lite version was facing limitations. 

This tool is designed to work completely independently with absolutely no installation required. If you have used Postman before, the user interface will feel very familiar to you.

## 🌟 Features
- **Fully Offline:** Requires no internet connection to load the tool itself.
- **No Installation Required:** Runs entirely in your browser just by opening a single file.
- **Lightweight & Fast:** Zero bloat, consuming minimal system resources.
- **Easily Extensible:** The code is straightforward. You can easily add your own custom features or use AI tools to expand its capabilities.

## 🚀 Usage
Using this tool is incredibly simple:
1. Download the code file (e.g., `index.html`) and save it to your computer.
2. Open the file using your preferred web browser (Chrome, Firefox, etc.).
3. Enter your HTTP method, URL, and parameters, then send the request! That's it!
